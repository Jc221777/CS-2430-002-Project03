# CS-2430-002-Project03

Reads a record of 12 experiments that have the atrributes weight and rating. We take this record and use three different strategies,Greedy,Brute force, and dynamic to create subsets. The created subsets must obey the constraint of being below 700 kg. The goal is to find the most optimal way to load these payloads into a space to acheive the highest rating while remaining below or eqaul to 700. The results of our startegies are displayed in the IO window when the program is run.
